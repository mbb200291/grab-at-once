Privacy Policy — Grab at Once!

Last updated: 2026-03-19

Overview

Grab at Once! is a Chrome extension that allows users to batch-download files by drawing a drag-selection box over links on a webpage.

Data Collection

This extension does not collect, store, transmit, or share any personal data or browsing information. Specifically:

  • No browsing history is recorded.
  • No URLs, page content, or user activity is sent to any server.
  • The only data stored is the extension's enabled/disabled state, saved locally in chrome.storage.local on your own device.

Permissions

The extension requests the following permissions:

  • storage — to save the on/off toggle state locally on your device.
  • activeTab / scripting — a click on the extension icon temporarily grants access to the current tab so the drag-selection UI can be injected. No data from the page is read or transmitted.

Third Parties

This extension does not use any third-party services, analytics, or tracking.

Contact

If you have any questions, please open an issue on the GitHub repository.
